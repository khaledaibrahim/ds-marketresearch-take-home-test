# Share of Search as a Proxy for Brand Consideration
### Tracksuit × Google Trends — Australian Market Study

**Author:** Khaled Ibrahim  
**Submitted:** April 2026

---

## Overview

This repository contains a full analysis of the relationship between **Share of Search (Google Trends)** and **brand consideration** (from Tracksuit's brand-health survey) across five Australian consumer categories spanning three purchase-intent levels.

**Core hypothesis:** *The SoS–consideration relationship is strongest in high-purchase-intent categories, where consumers actively research online before committing to a purchase.*

### Key findings

- Within-brand SoS–consideration correlations are **significantly higher in high-intent categories** (Mattresses, Car Insurance) than in low-intent categories (Chocolate)
- In high-intent categories, **search leads consideration by 1–2 months** — SoS functions as a real-time leading indicator of future survey outcomes
- Granger causality tests confirm that past SoS contains **incremental predictive information** about future consideration beyond what past consideration alone provides — predominantly in high-intent categories
- Brand **rank on search agrees with brand rank on surveys** most reliably in high-intent categories, providing an intuitive validation for client conversations

## Setup

### Prerequisites

- Python 3.10+
- A [SERPApi](https://serpapi.com/) key (free tier: 100 searches/month, the collection requires ~15 API calls total)

### Installation

```bash
git clone <your-repo-url>
cd ds-marketresearch-take-home-test

pip install -r requirements.txt

cp .env.example .env
# Edit .env and add your SERPAPI_KEY
```

### Data Collection

Collect Google Trends data for all five categories:

```bash
cd src
python data_collection.py
# This saves data/raw/all_trends.csv and caches each API call under data/raw/search_trends/
# Subsequent runs use the cache — no repeated API quota consumption
```

### Run the Analysis

```bash
jupyter notebook notebooks/analysis.ipynb
```

Or to regenerate the merged dataset and all figures programmatically:

```bash
cd src
python preprocessing.py   # generates data/processed/merged_data.csv
```

## Analytical Approach

### Five-layer analysis

| Layer | Method | Question answered |
|---|---|---|
| Cross-sectional correlation | Pearson r across brands per (category, month) | Do bigger brands dominate both search and consideration? |
| Within-brand longitudinal correlation | Per-brand Pearson r over time; levels and first differences | Does a brand's SoS co-move with its consideration over time? |
| Cross-lagged correlation | r(SoS at t−k, consideration at t) for k = 0..4 | Does search *lead* consideration, and by how many months? |
| Granger causality | statsmodels `grangercausalitytests`; ADF-gated first-differencing | Does past SoS predict future consideration beyond past consideration alone? |
| Rank correlation | Spearman r; rank slope charts at 4 time points | Does search rank agree with survey rank? |

### Key statistical choices

- **Fisher's z transformation** for averaging Pearson correlations (corrects for the bounded [−1, 1] scale)
- **ADF stationarity test** before Granger — first-difference if non-stationary (standard for brand-health series)
- **Anchor-brand normalization** for stitching multiple Google Trends batches onto a common scale (follows Danenberg et al. methodology)
- **Mann-Whitney U** for comparing r-distributions across intent levels (non-parametric, robust to non-normality)

## Key Design Decisions

**Why Share of Search rather than raw search volume?**  
Google Trends provides only relative indices (0–100), normalised within each query batch. Share of Search converts these into a share metric that is stable across time periods and interpretable as "fraction of category attention." This is the approach used in the academic SoS literature.

**Why consideration as the primary outcome?**  
Per the task brief, consideration is the brand-health metric most theoretically linked to search behaviour — search is an active expression of consideration-building. Awareness is more driven by passive advertising exposure; preference is a post-consideration narrowing that may lag SoS even further.

**Why high vs low intent as the moderating variable?**  
This directly operationalises the theoretical mechanism: in high-intent categories, search is instrumentally linked to purchase consideration. In low-intent categories, the causal pathway from "searched for brand" to "considering buying brand" is severed by the nature of the category.
